# Contribution Guidelines

Thank you for your interest in contributing to **Awesome Claude Code**! Please take a moment to review these guidelines before submitting a pull request.

## Adding a New Entry

### Requirements

- The project must be **directly related to Claude Code** (plugins, skills, MCP servers, hooks, tutorials, etc.).
- The project should have a **clear README** explaining what it does and how to use it.
- The project should be **actively maintained** (last commit within the past 6 months).
- The project should have at least **10 stars** on GitHub (exceptions for very new but high-quality projects).

### Format

Each entry should follow this format:

```markdown
- [Project Name](https://github.com/user/repo) - A concise description ending with a period.
```

- **Description** should be a single sentence, starting with a capital letter and ending with a period.
- **No promotional language** — keep it factual and concise.
- **No trailing whitespace.**

### Where to Add

- Add new entries **at the end** of the relevant section.
- If no existing section fits, propose a new one in your PR description.

## Pull Request Process

1. **Fork** the repository and create a new branch.
2. **Add your entry** following the format above.
3. **One entry per pull request** — this makes reviews faster.
4. **Write a clear PR title** (e.g., "Add project-name to MCP Servers").
5. **Verify the link** is correct and the project is accessible.
6. Submit your pull request and wait for review.

## Quality Standards

We aim to keep this list high-quality. Entries may be removed if:

- The project is abandoned (no activity for 12+ months).
- The project becomes irrelevant to Claude Code.
- The project violates its license or contains malicious code.

## Code of Conduct

Be respectful and constructive. We follow the [Contributor Covenant](https://www.contributor-covenant.org/) code of conduct.
